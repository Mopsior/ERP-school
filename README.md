# 🎒 ERP School Project
ERP system for B2C retail made in school to prepare for a vocational exam

I am creating this project as part of a class at my school to learn a new language and prepare to pass an exam using it.

> [!CAUTION]
> This is not a finished product ready for use in any business; it is intended solely for learning purposes, and its technical capabilities are limited to the mechanisms I will use on the exam.
> 
> This project may not be the best in terms of best practices for the language, and its appearance will change along the way, but I will use it to improve and strive toward those goals.

The system will store data as files on the disk, without using a real database, and the authentication system will be limited to the exam's constraints. I will also not use complex project configurations or any libraries that will not be available during the exam (due to the lack of internet access during the exam).

Project development is tracked using Linear.
